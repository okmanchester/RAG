## 已启用服务与备份

`RAG-Local-Supervisor` 使用当前用户的交互登录身份，登录启动并每分钟触发恢复检查，运行中 IgnoreNew。实际故障注入发现只配置 RestartOnFailure 未恢复被终止的监督进程，因此周期触发作为恢复保障；显式 stop 会先禁用该任务，start 重新启用。

实际 API 和 worker 异常退出均自动重启；监督进程被终止时 Job Object 回收 API/worker，旧状态超过 15 秒后变 stale，计划任务重新启动后恢复 fresh。无任务时心跳也持续刷新。进程存活不等同于任务健康，依赖观测与业务任务状态分别展示。
